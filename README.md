基于 ESP32-C3 的 DIY 电机动平衡仪，使用 TCRT5000 红外光电传感器获取转速与相位基准，MPU6050 六轴传感器采集振动信号，帮助定位电机转子的不平衡量大小与方向。

本项目为 DIY 原型，精度与专业动平衡仪存在差距，适合学习动平衡原理与嵌入式传感器融合。
给电摩.小牛九号极和等各品牌电动车电机都可以

工作原理
整体思路
电机动平衡的核心问题是：转子存在不平衡质量，旋转时产生离心力，引发振动。本项目通过影响系数法（影响系数法）来推算不平衡量的大小和相位。

基本流程：
测初始振动：电机在设定转速下运行，记录 MPU6050 测得的振动幅值与相位。
加试验配重：在转子已知位置添加已知质量的配重，再次测量振动。
计算影响系数：通过两次振动差值，得到“单位不平衡量产生的振动响应”。
推算不平衡量：利用影响系数反推原始不平衡量的大小与角度。

TCRT5000：转速与相位基准
TCRT5000 由红外发射二极管和光敏三极管组成，检测距离约 0.2–15 mm。在电机转子上贴一片反光标记，每转一圈传感器输出一个脉冲。
ESP32-C3 通过捕获脉冲间隔计算转速（RPM），同时以脉冲时刻作为相位零点——MPU6050 采集的振动信号相对于这个零点有固定的相位差，这个相位差就对应不平衡量的角度位置。
MPU6050：振动采集
MPU6050 内置三轴加速度计与三轴陀螺仪。本项目中主要使用加速度计：
电机旋转时，不平衡质量产生的离心力使支架/传感器产生周期性振动。
加速度计输出的是叠加了重力分量与振动分量的信号。
ESP32-C3 以远高于转速的频率采样加速度数据，提取与转速同频的振动分量（幅值和相位）。
注意：MPU6050 的陀螺仪部分对低频漂移敏感，本项目主要依赖加速度计做振动检测，陀螺仪可用于辅助判断传感器安装姿态。
